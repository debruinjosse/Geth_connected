============================================================
LANDING PAGE ENTRY POINT
============================================================

- /[locale]
- Examples: /en, /nl

- app/[locale]/page.tsx

Purpose:
- Renders the public homepage/landing page.
- Uses next-intl localized content.
- Wraps the page in PublicSiteChrome, which provides the navbar and footer.

============================================================
PAGE STRUCTURE
============================================================

1. PublicSiteChrome wrapper
- Provides public navbar.
- Provides public footer.
- Adds localized navigation links.
- Shows login/book-demo/dashboard links depending on auth state.

2. Hero section
- Contains the main landing headline.
- Contains the main description text.
- Contains the Book a demo CTA.
- Contains the See how it works anchor button.
- Contains trust bullets.
- Contains the desktop product visual.
- Contains the mobile product preview.

3. How It Works section
- Uses the deck-style five-step infographic component.
- Section id: how-it-works.

4. Card Deck Preview section
- Shows a preview of selected recognition cards.
- Uses carousel cards instead of exposing the full 53-card deck.

5. Audience cards section
- Three cards for companies, managers, and employees.
- Each card links to the book-demo flow.

6. Final CTA band
- Encourages visitors to book a demo or register.
- Uses a recognition/team image asset.

7. Footer
- Provided by PublicSiteChrome.
- Includes GETH branding, contact email, footer links, legal links, and registered year.
